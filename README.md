# Pandas-methods

Chuleta con las funciones de pandas que más uso para limpiar y analizar datos. La voy ampliando cuando me encuentro algo nuevo.

Está todo en [cheatsheet.md](cheatsheet.md):

1. Inspección básica y valores nulos
2. Duplicados, columnas, renombrar y reordenar
3. Tipos de datos, incluido el problema de los códigos que empiezan por 0
4. Texto y expresiones regulares
5. Filtros, conteos y agrupaciones
6. Fechas, `apply` / `map` y exportar a Excel con varias pestañas
7. Preparar los df antes de analizar: hojas, cabeceras, nombres de columna, tipos, sets y `concat` / `merge` / `join`, con [tiendas_prueba.xlsx](tiendas_prueba.xlsx) para practicar

Al final hay algunas diferencias que conviene tener claras (`map` y `replace`, `int` e `Int64`, `inplace`) y los comandos básicos de git.
